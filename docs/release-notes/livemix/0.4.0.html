LiveMix 0.4.0

  • LUFS 미터. 마스터 카드의 체인 버튼 옆에 LUFS 버튼이 생겼습니다 (설정 메뉴에도 있습니다). 마스터 출력의 라우드니스를 ITU-R BS.1770-4 / EBU R128 방식으로 잽니다: 순간(M, 400 ms)·단기(S, 3초)·통합(I, 초기화 후 전체)·범위(LRA)·트루 피크(최대)와 최대값, 목표(-14 유튜브·스포티파이 / -16 애플·팟캐스트 / -18 / -20 / -23 EBU / -24 ATSC)에 대한 막대와 최근 3분의 단기 곡선. 목표 ±1 LU 안이면 초록, 위면 빨강, 아래면 노랑입니다. 창은 닫아도 계속 재고, '항상 위'로 방송 화면 옆에 둘 수 있습니다. 통합값은 초기화 버튼으로 다시 시작합니다 (오디오 장치가 바뀌어도 이어서 잽니다).
  • 플러그인 관리의 검색. 플러그인 표 위에 검색 칸이 생겼습니다: 이름·제조사·형식의 어느 단어든 (예: waves comp, vst2) 치면 표가 그것만 보여 주고, 오른쪽에 '검색 결과 N개 / 전체 M개'가 나옵니다. 창을 열면 바로 타이핑할 수 있고, Esc로 지웁니다. 검색 중의 '전부 사용'은 보이는 것만 켭니다. 프리셋 만들기 창의 검색도 같은 방식입니다.
