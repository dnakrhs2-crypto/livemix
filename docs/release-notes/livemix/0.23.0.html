LiveMix 0.23.0

  • 마스터에도 플러그인 그룹. 마스터 카드에 마이크 카드처럼 ‘플러그인 그룹’ 단추와 번호 1~5가 생겼습니다. 마스터 체인의 플러그인을 골라 그룹으로 묶어 두고 번호를 누르면 그 플러그인이 한꺼번에 꺼지고(번호가 빨갛게), 다시 누르면 켜집니다. 마이크 그룹과는 따로 움직여서 마이크 그룹 핫키나 Stream Deck ‘플러그인 그룹 (전체 마이크)’ 키를 눌러도 마스터는 그대로입니다. 마스터 그룹은 설정의 ‘마스터 플러그인 그룹 1~5’ 핫키와 Stream Deck 플러그인 1.6.0의 새 ‘플러그인 그룹 (마스터)’ 키로도 껐다 켤 수 있습니다. 플러그인 1.6.0은 곰튀김.com/livemix의 Stream Deck 절에서 받습니다.
  • English. The master card now has plugin groups 1-5, like the mic cards. They are separate from the mic groups and have their own ‘Master plugin group 1-5’ hotkeys and the new ‘Plugin Group (Master)’ key in Stream Deck plugin 1.6.0.
  • 日本語. マスターカードにもマイクカードと同じプラグイングループ 1〜5 が付きました。マイクのグループとは別に動き、専用の「マスター プラグイングループ 1〜5」ホットキーと Stream Deck プラグイン 1.6.0 の新しい「Plugin Group (Master)」キーで操作できます。
